# ♠️ クラシック・ソリティア (Klondike Solitaire)

Bicycle風の本格的なトランプ絵柄、賢い先読みヒント、爽快なオートコンプリート機能を備えた、ブラウザで快適に遊べるクロンダイク・ソリティアのWebアプリケーションです。

PC（マウス・キーボード）とスマートフォン・タブレット（タッチ操作）のどちらでも滑らかに動作します。

---

## 🌟 特徴 (Features)

- **本格的なプレイングカード意匠:**
  - 規格（ポーカーサイズ比率 `2.5 : 3.5`）に忠実なカード外寸とグリッド配置
  - クラシックな上下対称（ダブルヘッド）の美しい絵札肖像画（J / Q / K）をSVGで完全独自描画
  - 伝統的なピップ（♠・♥・♣・♦）の幾何学レイアウトと、格式高い ♠A（Ace of Spades）
- **快適な操作性:**
  - **ドラッグ＆ドロップ**: カードの束（シークエンス）も自然に追従移動
  - **スマートタップ / クリック**: 移動可能な最適な場所（組札または場札）へ自動移動
  - **ダブルタップ / ダブルクリック**: 組札（Foundation）への即座の格納
- **先読みアシスト機能:**
  - **賢いヒント**: 「裏向きカードを開ける手」「組札へ送る手」を最優先でアドバイス。無意味な往復移動や手詰まり時の誤指示を排除した先読み検証ロジックを搭載
  - **1手戻す（アンドゥ）**: いつでも直前の盤面状態へ安全に復帰可能
- **全開放オートコンプリート:**
  - 場札がすべて表向きになると自動検知し、キングまで一気にリズミカルに回収するクリア演出
- **サウンド & 演出:**
  - Tone.jsによる心地よいカード操作音、クリア時のファンファーレと紙吹雪演出

## 🎮 遊び方 (How to Play)

1. **基本ルール (Turn 1 クロンダイク):**
   - **場札 (Tableau):** 赤と黒のマークが交互、かつ数字が1つ小さくなるように重ねていきます。
   - **空列:** キング（K）のみ配置可能です。
   - **組札 (Foundations):** 右上の4つのスロットに、各スート（♠・♥・♣・♦）ごとに **A から K** の順に積み上げます。
   - 4スートすべてのカードをKまで集めるとゲームクリアです。

2. **操作方法:**
   - **移動:** カードをドラッグ＆ドロップするか、カードを1回タップ（自動で最適な場所へ移動）。
   - **山札:** 左上の山札をタップすると捨て札へ1枚めくられます。
   - **ヒント / 戻す:** 画面上部のボタンからいつでも利用できます。

## 🛠 開発について (About)

このプロジェクトは、**生成AI（Gemini）を活用したバイブコーディング（対話型プログラミング）**によって作成されたシングルファイルWebアプリケーションです。

- **企画・仕様設計・ディレクション:** teratere
- **AIアシスタント (コード生成):** Gemini 3 Flash
- **構成技術:** HTML5 / Tailwind CSS / Vanilla JavaScript / Web Audio API (Tone.js) / Canvas-Confetti
- **完全スタンドアロン:** 外部サーバーや画像ファイルへの依存なし（単一HTMLファイル完結）
